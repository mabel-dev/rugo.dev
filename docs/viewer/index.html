Parquet, Avro and ORC viewer

Open a Parquet, Avro or ORC file and see its info, schema, column statistics and health, with no install and no account.

Your file never leaves your machine. Everything runs in your browser and reads the file straight from your disk. Nothing is uploaded, and there is no server doing the work.

Reads the metadata, not the file

Parquet and ORC describe themselves in a small footer at the end of the file, and Avro in a header at the start. The viewer reads just that, so even a file over a gigabyte opens in a fraction of a second and is never loaded into memory.

Avro and ORC, too

Formats that usually mean installing a tool to inspect. See an Avro schema and records, or an ORC file's stripes and column min/max, with a drop. Parquet runs on rugo's own code compiled to WebAssembly.

Remote files too

Paste a URL and the viewer reads it with HTTP range requests, still pulling only the bytes it needs. The server must allow CORS.

The same viewer has its own page for each of the other formats: avroviewer.com for Avro and orcviewer.com for ORC.
